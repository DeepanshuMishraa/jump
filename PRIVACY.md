# Jump Privacy Policy

Effective date: August 30, 2026

Jump is a Chrome extension for searching and switching between open browser tabs.

## Information handled

Jump temporarily accesses open-tab information, including page titles, URLs, domains, favicons, active states, window information, and visible tab previews. This information is used only to provide Jump's tab search and visual tab-switching features.

## How information is used

Tab information and previews are processed locally in the browser and are not sold, used for advertising, or sent to Jump's developer or external servers. Jump does not create user accounts and does not use analytics or tracking services.

Jump may open a Google search when a user enters a search query that is not a URL. Google handles that search according to Google's own privacy policy.

## Data retention and deletion

Tab information and previews are held temporarily in browser memory while Jump is running. They are cleared when no longer needed or when the extension is reloaded or closed. Jump does not store this information in a remote database.

## Remote code

Jump does not load or execute remotely hosted code. All extension code is included in the published extension package.

## Changes and contact

If Jump's data practices change, this policy will be updated in this repository. For privacy questions, contact the developer through the Jump GitHub repository.
